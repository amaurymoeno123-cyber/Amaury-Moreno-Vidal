### How I work

- Build in phases: data model and security first, tested logic second, design last.
- Row Level Security on every table from day one; secrets only in the host's environment.
- Reproduce production bugs before fixing them (for webhooks: signed with HMAC from the database itself).
- AI-assisted development with review: I own and can explain everything I ship.
